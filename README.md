Обзор
-------------

IntelliTrader — это полнофункциональный, высоконастраиваемый торговый бот для криптовалютных бирж. Он абсолютно бесплатен, поэтому используйте его на свой страх и риск. Всегда начинайте с [виртуальной торговли](#виртуальная-торговля). Присоединяйтесь к нашему [каналу Discord](https://discord.gg/rqfpn5a) для получения дополнительной помощи, поддержки и участия в обсуждениях.

##### Основные возможности

* Кроссплатформенность (Windows, Linux, MacOS)
* Глубокая и гибкая настройка
* Простота использования, высокая скорость и легковесность
* Способность адаптироваться к различным рыночным условиям
* Поддержка виртуальной (бумажной) торговли (Paper Trading)
* Поддержка бэктестинга (Backtesting)

Скриншоты интерфейса
-------------

### Панель управления (Dashboard)
Панель управления отображает ваши текущие открытые позиции, их среднюю цену покупки, текущую цену, текущую маржу доходности и время удержания позиций. Данные обновляются в реальном времени.
![Панель управления IntelliTrader](http://intellitrader.io/img/dashboard.png)

### Статистика и аналитика (Stats)
Раздел статистики содержит подробную информацию о вашей общей прибыли, ежедневных результатах, истории завершенных сделок и эффективности торговых правил.
![Статистика торговли](http://intellitrader.io/img/stats.png)

### Анализатор правил (Rules Analyzer)
Этот инструмент позволяет оценивать прибыльность каждого из сигнальных и торговых правил, помогая оптимизировать вашу стратегию.
![Анализатор правил](http://intellitrader.io/img/rules.png)

### Настройки (Settings)
Интерфейс настроек предоставляет доступ к базовым переключателям, а также к расширенному редактору конфигурационных JSON-файлов.
![Настройки программы](http://intellitrader.io/img/settings.png)

Начало работы
-------------

#### Системные требования

###### Windows, Linux и MacOS
Скачайте и установите .NET Core Runtime 2.1 (или новее) с [сайта Microsoft](https://www.microsoft.com/net/download/all).

#### Сборка проекта

Обычно собирать бота самостоятельно не требуется — проще скачать последнюю стабильную версию со [страницы релизов](https://github.com/jazzonaut/IntelliTrader/releases). Но если вы хотите собрать его из исходного кода:

1. Клонируйте репозиторий IntelliTrader локально.
2. В терминале Git выполните команду `git submodule update --init --recursive`, чтобы загрузить все необходимые субмодули.
3. Запустите файл `Publish.bat` (или `Publish.sh`, если вы работаете на Linux) — это создаст папку `bin` в директории `Publish`.
4. Запустите исполняемый файл IntelliTrader.

#### Первоначальная настройка
Бот готов к работе сразу после запуска с настройками по умолчанию. По умолчанию включена виртуальная торговля, поэтому вводить API-ключи на старте не требуется. Единственное, что может потребоваться изменить — это порт веб-интерфейса по умолчанию (7000). Подробнее об этом написано в разделе [Конфигурация веб-интерфейса](#конфигурация-веб-интерфейса).

#### Запуск

Просто запустите файл `IntelliTrader` для старта бота.
Прочитайте [Параметры запуска для Linux и MacOSX](https://github.com/jazzonaut/IntelliTrader/wiki/Runtime-options-for-Linux-and-MacOSX) для получения подробной информации по работе на этих платформах.

#### Поддерживаемые биржи
На данный момент полностью поддерживается биржа Binance.

#### Конфигурация правил (Rules)

Бот поддерживает гибкие сигнальные и торговые правила.
Правила делятся на:
* **Signal Rules (Сигнальные правила):** Используются для поиска точек входа и покупки новых пар.
* **Trading Rules (Торговые правила):** Применяются к уже открытым позициям (например, для динамического изменения процента тейк-профита, настройки уровней DCA или осуществления обмена/свопа).

Торговые процессы и логика
--------------

#### Виртуальная торговля

Виртуальная торговля (виртуальный аккаунт) включена по умолчанию и позволяет безопасно тестировать любые стратегии на реальных рыночных данных, не рискуя настоящими средствами. Торговая комиссия эмулируется параметром `VirtualTradingFees`.

#### Реальная торговля

Для реальной торговли вам необходимо создать зашифрованный файл с ключами API. Откройте `data/encrypt-keys`, введите ваши публичный и приватный ключи, сгенерируйте файл `keys.bin`, после чего сотрите ключи из конфигурационного файла во избежание утечки. Затем переключите `VirtualTrading` в значение `false`.

#### Механизм усреднения DCA (Dollar Cost Averaging)

DCA позволяет докупать актив при падении его цены ниже определенной маржи от средней цены входа. Это уменьшает среднюю цену позиции и позволяет выйти из сделки с прибылью при небольшом отскоке цены вверх.

При этом в системе реализована **оптимизация DCA на основе волатильности рынка**: шаг DCA (`NextDCAMargin`) динамически расширяется во время высокой волатильности спреда или сигналов, что предотвращает преждевременный закуп на стремительно падающем рынке.
